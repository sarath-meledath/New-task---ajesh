# HTML Multimedia Tasks — Source Files

This folder contains ready-to-run HTML source files and media assets for Tasks 1–5.

## Files by task
- `task1_music_player.html` — Task 1: Personal Music Player (`perfect.mp3`)
- `movie.html` — Task 2: Video Trailer Page (`trailer.mp4`, `poster.jpg`)
- `task3_accessibility.html` — Task 3: Accessibility & Broken Links Test (`nature.jpg`, `flower.jpg`; `missing_photo.jpg` is intentionally absent)
- `task4_audio_formats.html` — Task 4: Multi-Format Audio Compatibility (`song.mp3`, `song.ogg`)
- `portfolio.html` — Task 5: Mini Portfolio (`profile.jpg`, `introduction.mp3`, `introduction.ogg`, `project.mp4`)

## How to run
1. Extract the ZIP file.
2. Keep each HTML file and its referenced media files together in this folder.
3. Open an HTML file in a web browser.

## Media note
The audio is an original synthesized demo melody, not a commercial trending song. The trailer is a short fan-made practice animation created from generated artwork, not official *Jailer* movie footage. Use licensed music or official trailer media only when you have permission to do so.
